🔐 灰箱:已認證掃描(選用)

填入你自己的帳密,平台會先登入再掃描登入後的頁面。 帳號 / 密碼欄位由系統自動偵測,你不需要知道對方網站怎麼寫;密碼只用於登入、不會明文寫入紀錄。
若目標是 SPA / JS 應用(自動登入會失敗),請跳過此區,改用下面的 Authorization 權杖 / Cookie。

SPA / JS 登入時填這個:平台會 POST {"username","password"} 到登入 API、自動取得 token 帶上(像前端 JS 一樣)。 留空也會在表單登入失敗時自動探測常見登入 API。這樣你的 server log 就會看到真正的登入。

SPA / JS 應用(畫面由前端 JS 繪製)無法自動登入——請在瀏覽器登入後, 從開發者工具複製已登入的 Cookie 或 Authorization 權杖貼在下面。

SPA 的真正攻擊面在它呼叫的 API(F12 → Network → 複製那些 /api/…?參數 的網址)。 帶參數的端點會被當成注入點做主動測試。需同時勾選『主動測試』。

被動弱掃只做讀取式探測;主動測試會送出非破壞性的探測 payload。 兩者皆不提供任何規避偵測或破壞性功能。
